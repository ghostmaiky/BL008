## 📋 รายละเอียดชิ้นงานที่ส่ง

### 🏆 งานชิ้นที่ 2: การออกแบบเว็บหน้าแรก ของเว็บที่คิดว่าจะทำ
- **แนวคิด (Concept):** GAMEPULSE ศูนย์รวมแนะนำเกมน่าเล่น, รีวิวเกม, และตรวจสอบสเปกคอมพิวเตอร์
- **ดีไซน์ (Design):** ธีม Dark Cyber Gaming ผสมผสาน Glassmorphism และแสงนีออน Cyan/Purple
- **ฟังก์ชันสำคัญ:**
  - 🔍 **Live Search:** ค้นหาเกมตามชื่อ แนวเกม หรือสเปกคอมพิวเตอร์แบบเรียลไทม์
  - 🏷️ **Category Filter:** แยกประเภทเกมชัดเจน (ยอดนิยม, PC, มือถือ, เล่นกับเพื่อน Co-op, เกมฟรี)
  - 🖥️ **System Requirements Modal:** คลิกดูบทวิเคราะห์ "ทำไมถึงแนะนำ" และสเปกคอมขั้นต่ำที่ต้องใช้
  - 📐 **Design Blueprint (Mockup):** ภาพออกแบบหน้าเว็บต้นแบบ พร้อมจานสี (Color Palette) และ Tech Stack

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
- **HTML5:** โครงสร้างเว็บ Semantic ถูกต้องตามมาตรฐาน
- **CSS3:** Flexbox, CSS Grid, Custom Variables, Dark Theme, Glassmorphism
- **JavaScript (Vanilla JS):** ระบบกรองหมวดหมู่, ค้นหาเรียลไทม์, โต้ตอบ Modal
- **Deployment:** GitHub Pages (Host ออนไลน์ 24 ชม.)
- **Fonts & Icons:** Google Fonts (Kanit, Prompt, Chakra Petch), Font Awesome 6
