วัตถุประสงค์ของเว็บไซต์ (Objective)

ต้องการสร้างเว็บไซต์ GAMEPULSE เพื่อเป็นแหล่งรวมข้อมูลแนะนำเกมน่าเล่น รีวิวเกมทั้งบน PC, คอนโซล และมือถือ มีระบบเช็กสเปกคอมพิวเตอร์ และคะแนนรีวิวที่เชื่อถือได้ ตอบโจทย์ผู้เล่นเกมที่กำลังมองหาเกมน่าเล่น

ทฤษฎีสีและธีม (Color & Theme)

ใช้โทนสี Dark Cyber Gamer (พื้นหลังดำ #070913 เสริมด้วยแสงนีออน Cyan #00f0ff และ Purple #a855f7) เพื่อดึงดูดสายตาของกลุ่มเป้าหมายเกมเมอร์ และใช้สไตล์ Glassmorphism ดูทันสมัยเหมือนสตูดิโอเกมระดับโลก

โครงสร้างหน้าแรก (Homepage Layout)

จัดวางแบบ Hero Spotlight ด้านบนเพื่อสร้างความน่าสนใจ ตามด้วย Category Filter Tabs ที่กดเลือกหมวดหมู่ได้ทันที มีแถบค้นหา (Instant Search) และการ์ดเกมที่กดดูสเปกและรีวิวใน Modal ได้โดยไม่ต้องเปลี่ยนหน้า

เทคโนโลยีที่ใช้ในการพัฒนา (Tech Stack)

ใช้ Semantic HTML5 เพื่อโครงสร้างที่ถูกต้อง, Modern CSS3 Flexbox/Grid สำหรับรองรับหน้าจอมือถือ (Responsive), และ Vanilla JavaScript สำหรับระบบค้นหาและกรองข้อมูลแบบเรียลไทม์
